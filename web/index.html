READ THE SMALL PRINT

Deadlines, with context.

Source: endoflife.date, a community-maintained catalogue linked to vendor support policies. We check selected products weekly and preserve changed catalogues. Inventory entries stay in this browser; Save uses only this device’s local storage. The shared CoolCode visitor counter receives no inventory fields.

Version matching uses the longest exact numeric release prefix. An unknown cycle stays unknown. A support deadline is not a vulnerability assessment. Check the vendor policy before making an upgrade decision. Extended support is never assumed. Published deadlines are the final supported day. When no deadline is published, the Boolean source status is valid only at the catalogue check date; other assessment dates remain unknown. Use JSON to preserve exact inventory labels; CSV adds formula-safety prefixes where needed.
